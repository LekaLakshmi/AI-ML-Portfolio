# Happy vs. Sad Face Classification Using CNN

A binary image-classification project that uses a Convolutional Neural Network (CNN) to classify facial images as happy or sad.

- [Download Trained Model](https://drive.google.com/drive/folders/12-lZQdxdMpf7CmQ3uHziUe5DZln7Rxdu?usp=drive_link)

> Google Drive access is set to “Anyone with the link – Viewer.”

## Technologies

Python, TensorFlow, Keras, OpenCV, NumPy, Matplotlib and TensorBoard.

## Model Architecture

The CNN contains three convolutional and max-pooling blocks, followed by a dense layer and a sigmoid output layer for binary classification.

## Results

- Test accuracy: 100%
- Precision: 100%
- Recall: 100%

The test set was small, so these results should be interpreted cautiously.
